# Observation archives

These directories preserve dated calibration and review evidence in its original
language and bytes. Frozen inputs, outputs, invalid attempts, source snapshots,
hashes, and limitations remain part of each record. The archived rules describe
the recorded runs; the active review contract is
[`history/review-contract.md`](../../history/review-contract.md).

- [TPAMI calibration](2026-09-23_TPAMI校准/TPAMI与SA校准.md): nine valid votes on
  three reconstructed proposals, with incomplete source evidence and one format
  retry.
- [Review calibration](2026-09-23_评审校准/评审校准.md): the frozen A/B comparison
  and a separate targeted follow-up; these observations do not establish a
  general reduction in review errors.
- [VLA memory reassessment](2026-09-23_VLA-Memory复审/复审.md): reassessment of
  candidates 623–643, separate from the canonical ledger verdicts.

Some manifests retain absolute paths to external inputs and runtime snapshots
that are not included here. The archives are evidence records, not standalone
replay bundles or active calibration fixtures. Existing receipts document the
preserved scope. Product language checks exempt this directory, and Git preserves
original line endings and blank lines at end of file so source hashes remain
unchanged.
