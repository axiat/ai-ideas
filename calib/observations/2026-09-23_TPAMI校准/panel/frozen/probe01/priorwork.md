## Candidate evidence
C1: An author abstract describes multi-layer/coarse-to-fine multi-scale multimodal dictionary learning, learned dictionary and sparse-feature priors, optimization-to-module correspondence, and restoration/fusion experiments. It reports overall superiority but contains no quantitative effect size or attribution result.
C2: Official implementation was statically read. Its Stage invokes SolveFFT -> NetX and SolveLS -> NetD. Multi-scale branches, recurrent target/guidance updates, representation combination and output reconstruction are present. The repository has four task directories. No training/inference was run and no model-quality metric independently reproduced.

## Nearest Work
N1: Deep Convolutional Neural Network for Multi-modal Image Restoration and Fusion (CU-Net), arXiv v1 2019-10-09, https://arxiv.org/abs/1910.04066 . Abstract and full-text model/network methods were read. Section 3 decomposes each modality into common and unique convolutional sparse features. Restoration uses common plus target-unique components; fusion preserves both modalities' unique components. The model is unfolded into a network and already unifies restoration and fusion. Thus neither broad multimodal interpretation nor two task families is itself new. Candidate difference: layered/multiscale refinement and learned input-dependent dictionaries/priors. Its magnitude beyond N1 is not quantified in this packet.
N2: CU-Net+: Deep Fully Interpretable Network For Multi-Modal Image Restoration, ICIP 2021, https://rc.signalprocessingsociety.org/conferences/icip-2021/spsicip21vid611 . Official author abstract read, full text not obtained. Recurrent conversion better matches the original sparse model and relaxes common/unique feature-count constraints. It reports 0.16 RMSE and 0.66 dB improvement over CU-Net on depth SR and flash-guided denoising. These are N2's gains, not candidate gains. Candidate difference: multiscale and adaptive dictionary/feature priors plus fusion extension; recurrent interpretation itself is occupied.
N3: Multi-Modal Convolutional Dictionary Learning (MCDL), TIP 2022, DOI10.1109/TIP.2022.3141251, https://pubmed.ncbi.nlm.nih.gov/35025741/ . Author abstract read, full text not obtained. Uses common and unique convolutional dictionaries, shared common sparse representations across modalities, and alternating dictionary/code learning through ADMM in the DFT domain. Multimodal dictionary learning and alternating code/dictionary estimation are occupied. Candidate adds learned prior modules and hierarchical scale/layer interactions; a complete target objective comparison is unavailable.
N4: Revisiting Convolutional Sparse Coding for Image Denoising: From a Multi-Scale Perspective (MCSCNet), SPL 2022, DOI10.1109/LSP.2022.3175096, https://github.com/JingyiXu404/MCSCNet . Official README and complete core implementation model.py read; manuscript not obtained. The code uses 7/5/3 kernel sparse shrinkage branches in two rounds, residual refinement and summed reconstruction. Multiscale sparse unfolding already exists for single-image denoising. Candidate difference: multimodal coupled dictionaries/learned priors and a broader restoration/fusion framework.
N5: Deep Convolutional Dictionary Learning for Image Denoising (DCDicL), CVPR2021, https://openaccess.thecvf.com/content/CVPR2021/papers/Zheng_Deep_Convolutional_Dictionary_Learning_for_Image_Denoising_CVPR_2021_paper.pdf . Full-text Sections 3.1-3.3 plus architecture/algorithm excerpts read. Eq.(6)-(10), Algorithm1 and Figure1 explicitly learn both coefficient and dictionary priors, infer a dictionary for each input image, and alternate closed-form SolveX/learned NetX with closed-form SolveD/learned NetD under HQS. This is the closest adaptive solver precedent. Candidate difference: multimodal coupling and multi-scale/multi-layer structure; learning both priors and per-input dictionary adaptation cannot be counted as independent new ingredients.
N6: Learning Multiscale Convolutional Dictionaries for Image Reconstruction, arXiv2011.12815 (2020-11-25), TCI2022, https://arxiv.org/abs/2011.12815 . Full-text SectionIII read. Derives linear multiscale dictionaries from a U-Net decoder with convolution, scale separation and skip connections; learns task-driven encoding/decoding dictionaries using unrolled ISTA, including CT/MRI reconstruction. Multiscale dictionary design/unfolding has precedent. It is not a multimodal common/unique solver and does not establish complete occupation of the candidate.

Strongest Counterexample: N5 occupies adaptive dictionaries, learned code/dictionary priors and the SolveX/NetX/SolveD/NetD sequence; N1/N3 occupy multimodal sparse coupling and N4/N6 occupy multiscale dictionaries.
