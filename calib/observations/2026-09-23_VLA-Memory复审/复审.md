# VLA Memory 候选复审

按当前规则重新阅读 623–643 的原稿与查重材料后，建议将 **627、636、640 保留为 AwR，其余 18 项原稿维持 Reject，没有 SA**。636 与 640 是同一研究线，因此实际保留的是两条线。627 的保留依据最明确；636/640 的研究价值存在合理分歧；639 经对抗复核后暂维持 Reject，但值得保留争议记录。

这是对初步选题的复审意见，AwR 表示原问题具有可保留的研究价值，并有具体的有限修订条件。三名 agent 分组先读原稿与 prior，再核对旧票；另一名 agent 专门反驳拟晋级的四个候选，最后由主评审综合。各组只核查关键近邻原文，其他结论沿用冻结查重材料。此次没有执行完整 harness 投票矩阵，也没有改写历史 ledger，不能把这些意见称为正式重投结果或已证实的误拒。

| 624 | 当前写入丢失未来目标信息 | Reject，储备 | 成功率 oracle 与语义覆盖 oracle 有区别；原稿仍缺可执行定义及目标约束带来的实质增量。 |

| **627** | **恢复训练缺少必要历史** | **AwR** | **按观测歧义及恢复动作要求选择历史对，具有可核查的数据选择价值。** |

| **639** | **策略与验证器共享错误记忆** | **Reject，有争议** | **固定动作后仍混杂错误内容与动作的相关性；匹配后能留下什么独立认识尚不清楚。** |

这些 Reject 大多表示当前原稿缺少足够的独立贡献依据，并不证明该方向以后无法形成论文。补对照通常可以提高可信度，但只有原稿已经包含有价值的剩余问题时，才足以支持 AwR。

## 优先保留 627

627 的可保留主张是：**在相同数据预算下，优先选择当前观测难以区分、但历史能够区分所需恢复动作的样本，是否能改善策略对历史的使用。** 原稿已经包含观测匹配、恢复动作差异、固定失败数及历史—动作关系置乱，因此这项贡献并非复审时另行构思。

IntervenGen 已使用恢复干预、BC-RNN 以及隐藏几何造成的歧义。627 无法主张首次发现历史有助恢复，其新增部分须限定为数据选择准则及其独立收益。[IntervenGen §III、§V–VI](https://arxiv.org/html/2405.01472)

有限修订需要完成两件事：

1. 配对规则须保证两段历史对应不同的正确恢复要求。两名专家给出不同动作标签还不够；需要证明在同一当前观测下，可成功恢复的动作集合确实不相容，且历史足以区分它们。
2. 与 IntervenGen 式恢复数据进行等预算比较，保留其 BC-RNN 和反馈能力，并匹配失败类型、动作覆盖和样本量。这样才能检验数据选择的作用，而非更多恢复数据或不同任务难度。

最强反对理由是：收益可能完全来自动作覆盖或标签平衡。若公平对照已经解释收益，当前贡献需要降回 Reject。尚未跑出提升本身不是本次 AwR 的阻碍，原稿的方法定义与归因缺口才是修订内容。

## 将 636 与 640 合为一条线

这条线关注：**准确历史已经提供给策略时，训练位置频率是否仍改变它依据历史纠正动作的能力。** 它区分记忆存储、检索与动作使用，能够直接影响“先修记忆还是先修策略”的研究选择。

HALO 的空间捷径观察支持研究动机；KAFT 已研究参数知识与上下文响应，以及反事实训练。因此新颖性不能来自“先验可能压过外部证据”这一通用命题，反事实配对训练也不能直接作为新算法。该线保留的是受控训练分布下的动作侧诊断，当前只足以支持有争议的 AwR。[HALO §VII-C](https://arxiv.org/html/2606.25136)、[KAFT](https://arxiv.org/html/2211.05110)

636 的 correct−blank 交互可能只是空记忆表现改变；640 的 correct−wrong 交互也可能只是错误记忆更少诱导错误。两者都不能只报一个差之差后宣布正确记忆失效。有限修订是：

1. 分别报告 correct、wrong、blank 三臂，按目标位置及其与训练先验是否冲突分层，同时检查首次动作是否响应有效历史。
2. 加入目标位置直接可见或明确告知的执行能力对照，判断稀有位置是否只是动作能力较弱。识别目标首先限定为训练频率干预下的行为变化，进一步解释参数内部机制须另有证据。

若控制动作能力后只剩已有上下文冲突规律的普通复现，诊断价值仍不足以支持首篇。独立对抗评审对此保留合理分歧，本次没有把它评为 SA，也没有将 636 与 640 计算为两项独立创新。

## 639 暂不直接升级

初审支持 AwR 的理由是：固定同一个物理失败动作后，比较验证器在共享错误与独立错误记忆下的误接受率，可以分开动作提议质量与验证错误。CoVe 已表明共享错误内容可能干扰验证；MemER 也观察到错误文本记忆干扰视觉信息的使用。这些材料提供动机，但没有给出候选实验的结果。[CoVe §3.3](https://arxiv.org/html/2309.11495v2#S3.SS3)、[MemER §4.1](https://arxiv.org/html/2510.20328v1#S4.SS1)

对抗复核指出，**同源错误往往恰好解释并支持该失败动作，独立错误可能与动作无关。** 只匹配错误条数和事实类别，仍可能把内容相关性误记为同源性效应。自然提议与额外构造动作混在一起也会改变被测风险。

匹配动作相关事实、分开自然与构造提议、在相同成功动作接受率下比较误接受率，均属有限修订。然而原稿没有进一步说明：完成这些匹配后，预期留下的哪种知识超出了已知共同失效。当前证据下，我倾向保留 Reject，而非把有价值的安全问题直接等同于有价值的独立论文。分组评审的 AwR 意见与对抗评审的 Reject 意见均原样保留。

## 研究脉络

值得继续的两条线都指向 **历史信息是否真正影响了所需动作**：636/640 检查准确历史已输入后的使用情况，627 检查训练数据是否提供足够的历史辨识要求。它们可以共用任务和评测，但各自贡献仍须独立成立。当前更适合优先完善 627 的方法定义，636/640 作为相关的诊断方向保留。

628 的探索混淆、629 的来源相关性、642 的控制器历史，可以作为这些工作的评测检查项。它们暂时没有足够依据单独支撑论文，仍可能帮助避免错误归因。642 尤其不能直接指控 MemER 的无历史对照受到低层记忆污染：MemER 原文明确将该低层策略描述为 Markovian。[MemER §3.1](https://arxiv.org/html/2510.20328v1#S3.SS1)

本次变化主要来自对原稿剩余价值和有限修订的重新判断。大多数旧实验批评仍然有效；当前规则允许将这些具体缺口与保留价值同时写清楚。
