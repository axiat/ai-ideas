# VLA Memory 630–636 规则复审

本次为 agent 按现行 `review-contract.md` Gates 进行的原稿复审，不是正式 harness 矩阵重新投票。先读冻结候选和 prior packet 独立判级，再经 provenance 定位旧三席评审。未修改代码或 ledger，未运行外部 CLI 模型。未运行实验本身不扣级；缺少积极价值依据仍可 Reject，且无需认定 CRITICAL。本组没有 SA。

**630｜按回访成本写入：Reject，低优先级。** 剩余差异是预测物理回访成本并测试单向路线，DTR 已明确保存不可重建信息，成本留存本身没有新意。旧评审把“未达明确接收”直接用于拒绝偏严，但未说明非平凡改动、缺少成本启发式和 MemER 对照的判断有效。补齐两类对照并限定路线交互主张，是有限修订；目前仍缺独立收益的积极依据。新增写入与行动联合优化算法才能建立价值时，已属新贡献。初判 AwR 经强反驳后改为 Reject，并非因一般机制已知便认定机器人结果全被覆盖。

**631｜带可见区域的负记忆：Reject。** Nie 2016、Wong 2013 已保存失败搜索的可见覆盖并据此规划；剩余价值仅为有限存储下显式记录的效率优势，原稿未解释为何胜过已有表示。旧评审对任务命题的直接覆盖判断成立；将所有晋级要求统一为明确接收过严。有限修订是保留 GenMOS、Bejjani 的可见性能力，并仅匹配决策前相机轨迹。置乱标签无效也可能因其他输入已含覆盖信息，不能否定可见性条件化；这些修订尚未补出独立贡献。（本次仅依据旧 packet。）

**632｜坐标系与接触记忆：Reject。** 尚有价值的问题是遮挡和基座转动后，何种误差结构导致插入失败；一般坐标变换已知不能覆盖全部目标结果。但现稿没有强先验支持出人意料的新增认识。旧评审关于共享误差可抵消、物体到机器人变换未说明的批评有效；“实验未验证”本身不构成扣级。有限修订是保留世界坐标基线的相关协方差与历史校正，并明确漂移交互估计量。若最终仅展示已知误差传播规律，仍不足接收。（仅依据旧 packet。）

**633｜动作等价类替代身份：Reject。** 潜在价值是澄清延迟工具选择需要哪些实例关联，既有 affordance equivalence 并未证明部分可观测任务可删身份。旧评审不能把缺少特殊晋级条件当作普通否决，但实例绑定未定义的批评成立：能力类别仍须对应可选择的工具。有限修订是列清删除与保留的关联，并将非劣判据定义为类别减身份成功率区间下限高于 −3%。同字节下持平没有显示资源节省，当前仍缺独立知识收益的依据。（仅依据旧 packet。）

**634｜事件先后记忆：Reject。** SafeManip 已覆盖污染、清洗、再接触的任务规则，Reward Machines 已提供事件驱动状态；剩余贡献只能来自具体表示优势。旧评审的直接任务覆盖及监督不对等疑虑有效；一般原理已知仍不能直接覆盖任意新架构。有限修订是说明 precedence 更新，并向状态机、时间戳模型提供同等规则和事件证据。最终视觉状态相同并非完整任务状态相同；若仍只重复这一差异，补齐实验也不能产生新认识。（仅依据旧 packet。）

**635｜环境姿态替代内部记忆：Reject。** 物理可写容量与任务可完成性的关系保有区别，但 Peshkin 已给出外存容量与无内部记忆控制的联系，RFID 工作已展示跨机器人复用。旧评审对容量估计错配的判断成立；缺少 assumption-removal 特殊条件仅应转普通评定。有限修订是交叉操纵可写姿态数与所需 bit 数，并校准解码错误及动作成本。当前三档任务需求加重置只检验具体替代；形成有新预测的噪声容量规律仍需独立论证，不能预支为 AwR。（仅依据旧 packet。）

**636｜位置先验与准确记忆冲突：AwR，优先保留。** 积极价值是区分 VLA 的检索不足与正确证据输入后的动作依赖；HALO 的空间捷径观察及 Lu 的检索门控结果提供相关依据，尚未识别该动作侧交互。旧评审把跨领域机制、反事实训练已知推成整体无值过强；空记忆基线改善可制造负交互的反例完全有效。有限修订是用已有错误／正确记忆臂测冲突状态的动作纠正，并控制各抽屉执行熟练度。诊断可独立成立；若保留修复贡献，须纳入 HALO 式监督对照。10 点仅作价值停止线，不能否定较弱机制。

**原论文核查。** 本次只完成一轮关键近邻读取，没有重新进行全面新颖性检索。636 的 [HALO 原文 §III、§VII-C / Figure 7](https://arxiv.org/html/2606.25136) 确认：作者以 VQA 监督引导检索，并用定性可视化展示无关纸卷位置影响动作预测；该证据支持空间捷径的研究动机，不能直接证明位置频率先验压制已注入的正确记忆。630 的 [DTR 原文 §2、§4.1](https://arxiv.org/html/2006.09616) 确认：重建成本进入驱逐评分，不可重建值受到保护；这加强其一般机制重合判断。Lu 及人类外部采样论文的 PMC 网页本次被验证页阻断，相关判断明确沿用旧 packet，未记为重新读通。

**本组优先级。** 636 是唯一建议继续有限修订的候选；它具有动作侧诊断的研究价值，但原稿尚不足 SA。其余均不因“修得动”得到 AwR。630 可留作低成本对照想法；632、633、635 可保留问题记录，待新增实质依据再评价；631、634 的原始主张最接近已覆盖结果。

**两项最强反对意见。** 第一，636 可能只是把 RAG 知识冲突搬到抽屉任务，HALO 也已处理历史捷径；AwR 必须依赖正确记忆输入后仍能识别的动作选择机制，而不能依赖换领域或另报一个掉点。第二，改变位置训练频率同时改变空记忆命中率和各抽屉动作经验；即使得到负交互，也可能没有记忆抵抗。已有配对状态、正确／错误记忆臂可以承载第一项修订；若执行熟练度控制后效应消失，应停止该机制主张，而非追加另一套贡献维持接收。
